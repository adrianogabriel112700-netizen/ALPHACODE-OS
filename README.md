# ALPHA CODE SYSTEM - Painel Administrativo

Sistema privado e seguro para gerenciamento interno de clientes, projetos e finanças da empresa Alpha Code.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend**: HTML5, CSS3 Moderno (CSS Variables, Flexbox/Grid), JavaScript Vanilla ES6+
- **Backend**: Node.js, Express, JWT, bcryptjs, Helmet, Rate-Limit
- **Banco de Dados**: PostgreSQL

---

## 🚀 Como Executar o Projeto

### 1. Pré-requisitos
- Node.js instalada (v18+)
- PostgreSQL rodando localmente ou via Docker
